WORKFLOWS:
----------
1. First Page:
   figma-to-blockstudio <url> --page home
   → Creates complete structure

2. Incremental Update:
   figma-to-blockstudio <url> --page about --update
   → Reads state, detects similarities, updates

3. Full Document:
   figma-to-blockstudio <url> --full-document
   → Processes all pages at once

4. Legacy Mode:
   figma-to-blockstudio <url> --legacy
   → Generates single design-spec.md (v1.0)

SIMILARITY DETECTION:
--------------------
Score = FieldTypes(40%) + Layout(30%) + FieldCount(20%) + Name(10%)

Decision tree:
- ≥95%: Auto-add variant (no confirmation)
- 60-94%: Ask user (variant or new block?)
- <60%: Create new block (auto)
